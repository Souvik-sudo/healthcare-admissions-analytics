# Healthcare Admissions Analytics Dashboard

> An interactive Power BI dashboard analyzing healthcare admissions, clinical operations, patient demographics, billing, insurance, and data quality.

![Healthcare Admissions Dashboard](Screenshots/01_Executive_Overview.png)

---

## 📌 Project Overview

A Power BI portfolio project built to transform raw healthcare admission data into an interactive analytical dashboard.

The project covers:

- Data cleaning and transformation using Power Query
- Star-schema data modeling
- DAX measures and time intelligence
- Interactive dashboard design
- Clinical, financial, and patient-level analysis

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Star Schema
- Data Visualization

---

## 📊 Dashboard Pages

| Page | Focus |
|---|---|
| **Executive Overview** | KPIs, billing trends, admissions, and medical conditions |
| **Clinical Operations Analysis** | Length of stay, test results, age groups, and admissions |
| **Finance & Insurance Analysis** | Billing, insurance performance, and financial analysis |
| **Patient & Admission Analysis** | Demographics, medication, blood type, and admission patterns |

---

## 🔍 Key Project Work

- Cleaned and transformed **55,500 original records**
- Removed **534 duplicate records**
- Final dataset: **54,966 records**
- Identified and handled invalid negative billing values
- Created derived fields including `Billing_Flag`, `LengthOfStay`, and `AgeGroup`
- Built a star-schema data model
- Developed DAX measures for KPIs, billing, growth, data quality, and clinical metrics
- Designed a four-page interactive Power BI dashboard
